# Homepage Philosophy

Forget everything traditional contractor websites do.

Do NOT start by talking about Skyline.

Start by talking about the visitor.

Visitors arrive with anxiety.

"My building is leaking."

"My ceiling is cracking."

"My apartment committee is blaming me."

"My hotel cannot shut down."

"My factory floor is damaged."

The homepage should immediately communicate

"We understand exactly what you're experiencing."

Once that happens,

trust begins.
